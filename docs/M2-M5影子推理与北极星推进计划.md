# M2—M5 影子推理与北极星推进计划

> 版本：v1.0  
> 状态：执行中  
> 编制角色：架构师 × 工程执行  
> 适用范围：`daoti` workspace

## 1. 目标与真实性边界

本计划的目标是把 M1 的源码提取、轻量训练和权重导出能力，推进为可观测、可验证、可降级的跨平台信号翻译链路，最终服务于三平台软件互调北极星目标。

当前必须如实区分：

- M1 已具备提取骨架、2048 维编码、训练闭环和 `DAOTIBLT` 导出能力。
- M2 已具备 ELF syscall 只读观测、影子推理和 JSONL 外化能力。
- `hello_dynamic` 当前仍在 ld-linux 初始化阶段以退出码 127 失败，不能作为成功运行证据。
- 已生成超过 10,000 条可解析影子记录，但记录主要来自 `hello_dynamic` 的初始化失败路径，不能作为完整 ELF 成功执行或模型泛化准确率证据。
- B2 在任何阶段都不得未经验证替换 Linux x86-64 syscall ABI；硬编码桥接必须保留为安全降级路径。

## 2. 总体安全原则

1. 先观测，再验证，再建议，最后才考虑受限指导。
2. 影子预测不得改变 syscall 返回值、内存模型或进程控制流。
3. 未训练、低置信度、编码失败、解码失败和模型异常时明确降级，不猜测。
4. 所有阶段必须有可复现输入、命令、输出产物和失败记录。
5. 不以宿主输出注入、固定地址覆盖、放宽断言或假成功替代真实验收。
6. 训练数据、权重、影子记录和评估报告均纳入版本化或可追溯存储。

## 10. 工程监督与质量门禁
